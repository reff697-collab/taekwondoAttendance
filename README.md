# 🥋 Taekwondo Attendance

Aplikasi **pencatatan kehadiran atlet Taekwondo** berbasis mobile yang dikembangkan menggunakan Flutter.

## 📋 Deskripsi

**Taekwondo Attendance** merupakan aplikasi mobile yang dirancang untuk membantu proses pencatatan dan pengelolaan kehadiran atlet dalam kegiatan latihan Taekwondo.

Aplikasi ini membantu menggantikan pencatatan kehadiran secara manual sehingga data absensi dapat dikelola dengan lebih **terstruktur, praktis, dan mudah dipantau**.

## ✨ Fitur Utama

* 📝 Pencatatan kehadiran atlet
* 👥 Manajemen data atlet
* 📅 Pencatatan kehadiran berdasarkan jadwal latihan
* 📊 Monitoring data kehadiran
* 🔐 Autentikasi pengguna
* 📱 Antarmuka mobile yang sederhana dan mudah digunakan

## 🛠️ Teknologi yang Digunakan

* **Flutter**
* **Dart**

## 🎯 Tujuan Pengembangan

Project ini dikembangkan untuk membantu proses administrasi latihan Taekwondo, khususnya dalam **pencatatan dan pemantauan kehadiran atlet** secara digital.

## 📄 Lisensi

Project ini dibuat untuk keperluan pembelajaran dan pengembangan aplikasi mobile.
